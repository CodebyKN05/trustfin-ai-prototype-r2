\chapter[PROJECT PLANNING]{Project Planning}

This chapter presents the development work plan and its Gantt chart, showing the main dependencies between the model, explanations and application.

\section{Development Work Plan}
Before model training, there is data preparation and feature definitions. Explanation integration follows the fitted model and the interface and API build around the common response structure. The later activities overlap testing/documentation.
